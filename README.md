# AI Financial Risk Analytics Engine

This project is a full-stack financial risk analytics engine designed to evaluate portfolio risk using a Python-based API layer and a trained Decision Tree model. A native C risk-scoring library is also included, but the current API scoring path uses the Python model.

## Project vision

The engine calculates portfolio risk using macroeconomic signals, concentration exposure, liquidity stress, and default probability. It provides operational outputs such as:

- portfolio risk score
- risk band classification
- regulatory readiness signal
- forward-looking stress alerts
- API and dashboard integration

## ML workflow

The project follows this end-to-end sequence:

1. **Dataset:** generate `data/synthetic_portfolio_risk.csv` with 8,000 labeled examples.
2. **Preprocessing:** load numeric features from the CSV and apply median imputation in a scikit-learn pipeline. Scaling is not needed for tree-based models.
3. **ML model:** train a `DecisionTreeRegressor` and save the complete preprocessing/model pipeline.
4. **Risk prediction:** the FastAPI service loads the saved pipeline, predicts a 0–100 score, then derives a risk band and alerts.
5. **Streamlit dashboard:** submit portfolio inputs to the API and display the prediction, indicators, and alerts.

The training examples are synthetic, with labels generated by the existing weighted formula; they are not observed financial outcomes.

## Tech stack

- Python 3.11+
- FastAPI for backend services
- scikit-learn DecisionTreeRegressor for portfolio risk scoring
- C native risk-scoring library (not used by the current API scoring path)
- Streamlit for the portfolio risk dashboard
- SQL schema for persistence
- pytest for verification

## Quick start

### Start from Windows File Explorer

After installing the project dependencies, double-click `Open Dashboard.bat` in the project folder. It opens the dashboard in your browser and starts the API and Streamlit in separate command windows. Keep those windows open while using the dashboard.

1. Create a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate      # Windows
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Optional: build the C library (the current API scoring path does not use it):

```bash
make c-build
```

4. Start the API in a terminal:

```bash
PYTHONPATH=backend/python uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

On Windows PowerShell, you can also use:

```powershell
$env:PYTHONPATH = "backend/python"
py -3.12 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

5. In a second terminal, start the Streamlit dashboard:

```bash
streamlit run frontend/streamlit_app.py
```

On Windows PowerShell:

```powershell
py -3.12 -m streamlit run frontend/streamlit_app.py
```

The dashboard sends assessments to the FastAPI service at `http://127.0.0.1:8000`. Set `RISK_API_URL` if the API runs at a different address.

## Machine-learning model

The API uses a saved `DecisionTreeRegressor` from
`backend/python/models/portfolio_risk_decision_tree.joblib`. Its training data is
`data/synthetic_portfolio_risk.csv`, generated by `backend/python/train_model.py`
with 8,000 deterministic synthetic examples (seed 42). It predicts a numeric
0–100 score from volatility, exposure, liquidity, default probability,
concentration, and asset count; the API maps that score to a risk band and alerts.
The targets are generated from the project's weighted formula, not from observed
financial outcomes, and the model has not been validated for real investment or
lending decisions.

After installing dependencies, train or recreate both files from the project root:

```bash
python backend/python/train_model.py
```

The script prints holdout MAE and R² as a check of how well the model approximates
the synthetic formula. These metrics do not measure real-world predictive
performance. The API reports an explicit error if the saved model is missing or
incompatible; it does not silently fall back to another scoring method.
